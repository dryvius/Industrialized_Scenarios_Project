# 挖掘机模型优化方案说明

> 本文档是程序化挖掘机的**网格、朝向与机构外观**约定。  
> 关节驱动、行进和液压长度联动见 [`场景动画与动作实现说明.md`](./场景动画与动作实现说明.md)。  
> 碰撞盒仍按 `VEHICLE_SCALE.excavator` 生成，不跟随网格，见 [`场景穿模与物理碰撞方案说明.md`](./场景穿模与物理碰撞方案说明.md)。  
> 场景基线见 [`工业基建施工场景-项目生成说明.md`](./工业基建施工场景-项目生成说明.md)。  
> 定位：等轴测、示意级低多边形。中距离能认出履带、工作装置和铲斗开口，不做电影级写实，不换 GLTF。

实现集中在 `ExcavatorBuilder`。液压缸网格由三台车共用的 `createHydraulic` 生成。履带滚动标记在 `trackAnim`。

---

## 1. 目标与边界

### 1.1 要达到的效果

| 项 | 要求 |
| -- | ---- |
| 铲斗 | 斗耳套在斗销上，斗底朝下，斗口收回朝向斗杆和机体，斗齿在下刃口 |
| 履带 | 能看出履带板、履刺、导向齿、后驱动轮和前导向轮、支重轮、外侧裙板 |
| 液压缸 | 能看出缸筒、活塞杆、缸盖和销耳；挖机上的缸比吊车、搅拌车更粗 |
| 剪影 | 动臂、斗杆、驾驶室在现有橙色机身上仍能一眼分开 |

### 1.2 明确不做

- 把整只铲斗绕销转 180° 来「把斗口翻到里面」。那样斗底会翻到上面。
- 为铲斗单独做一套会随弯曲角重算的 H 形连杆机构。当前是缸销直接穿斗背销耳。
- 改 `joint_*` 的建造转角来修斗的朝向。控制器把建造时的转角当成基姿，再叠加行进和挖掘偏置。
- 给端头包络段的履带板打滚动标记。它们会沿直线滑动，而不是绕着链轮走。
- 加大 `createHydraulic` 的默认半径。吊车和搅拌车共用这组默认值。
- 驾驶室内饰、逐节履带销、真实软管动力学。软管是挂在父关节上的静态管子。

热更新不会重建 Three 场景。改建造器后需要刷新页面。

## 2. 必须保住的契约

`tagAnimatable` 和 `ExcavatorActionController` 按名字找节点。网格可以换，下面这些名字和建造转角不要改。

| 节点 | 父级 | 建造时的局部变换 |
| ---- | ---- | ---------------- |
| `joint_slew` | 根 | `y = 1.45` |
| `joint_boom` | 上车 | `(-0.35, 0.8, 1.5)`，`rotation.x = -0.72` |
| `joint_stick` | 动臂膝部 | `z = 2.6`，`rotation.x = 1.55` |
| `joint_bucket` | 斗杆 | `z = 2.9`，`rotation.x = 0.55` |
| `joint_track_L` / `joint_track_R` | 根 | `x = ±trackSpread` |

动臂膝部是 `joint_boom` 下的静态组，`position.z = 2.5`，`rotation.x = 0.38`。它没有关节名，控制器不驱动它。不要为了斗的姿态去改这个角度。

动画键仍是 `slew` / `boom` / `stick` / `bucket` / `trackL` / `trackR`。

相对建造基姿的偏置（`ExcavatorActionController`）：

| 关节 | 限位 | 行进收臂 | 挖掘振幅 |
| ---- | ---- | -------- | -------- |
| 铲斗 | `-0.15` ~ `0.28` | `+0.18` | `±0.2` |

控制器在构造时立刻套上收臂姿态，所以停掉演示后看到的铲斗大约是 `0.55 + 0.18 = 0.73`，不是建造器里写的 `0.55`。调斗壳俯仰时按这个可见姿态算。

液压锚点：

| 名字 | 父级 | 局部位置 |
| ---- | ---- | -------- |
| `anchor_boom_from_L/R` | 上车 | 相对动臂中线对称，`y = -0.55`，`z = 0.35` |
| `anchor_boom_to_L/R` | 动臂 | `x = ±0.38`，`y = -0.42`，`z = 1.65` |
| `anchor_stick_from` | 动臂膝部 | `(0, 0.48, 0.85)` |
| `anchor_stick_to` | 斗杆 | `(0, 0.32, 0.18)` |
| `anchor_bucket_from` | 斗杆 | `(0, 0.4, 1.65)` |
| `anchor_bucket_to` | 铲斗 | 斗背销耳，由壳体俯仰换算，不要再写成固定的外侧点 |

缸体子节点名必须仍是 `hyd_barrel`、`hyd_collar`、`hyd_cap`、`hyd_rod`、`hyd_eye_from`、`hyd_eye_to`。`layoutHydraulic` 按这些名字摆零件。

比例常量（`VEHICLE_SCALE.excavator`）：履带长 `4.2`，轨距 `1.4`，斗宽 `1.4`，机棚顶近似 `3.0`。碰撞盒用的是这组数，不是铲斗网格的包围盒。把斗加长不会自动改碰撞。

## 3. 铲斗

### 3.1 原先的问题

第一版是封闭盒子，销没有穿过斗耳，斗齿也不在刃口上。改成开口壳体之后，斗口朝向了斗杆外侧。若把壳体俯仰直接加上 `π`，整只斗会倒置：斗底朝上，斗齿指回斗杆里面。可见姿态要的是斗底朝下、斗口朝机体。

### 3.2 朝向怎么摆

壳体截面画在 XY 平面里，沿 Z 挤出斗宽，再绕 Y 转 `+π/2`。

- 截面 `+X` 变成壳体局部 `-Z`，这就是斗口，朝向斗杆。
- 截面 `-Y` 仍是壳体局部 `-Y`，这就是斗底。
- 截面上的斗销点 `(0.02, 0.16)` 被平移到壳体原点，和 `joint_bucket` 的销对齐。

壳体再绕 X 俯仰 `BUCKET_SHELL_PITCH = -1.05`。收臂可见角约 `0.73` 时，斗口相对斗杆的合角约 `-0.32`：朝机体，并略向下。挖掘限位里这个合角仍为负，斗口不会在弯曲过程中翻到外侧。

不要用 `rotation.y = -π/2`，那是斗口朝外的旧方向。也不要在 `-1.05` 上再加 `π`。

### 3.3 网格

| 零件 | 做法 |
| ---- | ---- |
| 斗壁 | 闭合的厚壁截面，`ExtrudeGeometry`，`curveSegments = 12` |
| 侧板 | 另一块实心斗形截面，贴在斗壁两端外侧，厚度 `0.07` |
| 斗耳 | 两侧板套住斗销，中间有横梁；销长约 `斗宽 × 0.62`，能放进斗杆颊板之间 |
| 刃口 | 金属刀板沿刃口切向；5 颗斗齿，齿尖沿刃口指向斗口且略向下；两角各一颗边齿 |
| 斗底 | 三道耐磨条贴在腹板外侧，方向跟腹板切线 |
| 斗背 | 两片销耳、一根销、一块筋板。`anchor_bucket_to` 就在这根销上 |
| 材质 | `materials.get('bucketShell', …)`，独立键，`DoubleSide`。不要改共享的轮胎黑材质 |

斗齿、刀板和边齿的长度方向用四元数对齐，不要再写一个固定的 `rotation.x`。截面一改，固定角度就会和刃口错开。

铲斗油缸从斗杆上的 `anchor_bucket_from` 连到这根斗背销。建造时的第二点要先乘上铲斗的 `rotation.x = 0.55`，否则第一帧缸和锚点是分开的。控制器随后会按锚点重排。

侧板几何两面共用一块。改其中一面的几何会同时改另一面。

## 4. 履带

左右履带各是 `joint_track_L` / `joint_track_R`。一块履带板是一个组：底板、两道履刺、中间导向齿。履刺在板的外侧（局部 `-Y`）。上支板 `rotation.x = π`，让履刺仍朝外。

只有直线段参与滚动：

| 车道 | 数量 | 标记 |
| ---- | ---- | ---- |
| 下支 | 20 | `markTrackShoe`，`lane: 'bottom'`，并写入该段的 `zMin` / `zMax` |
| 上支 | 18 | 同样标记，`lane: 'top'` |
| 前后包络 | 每端 8 个采样（含端点） | **不标记** |

`VehicleMotionController` 在构造时缓存已标记的板和链轮。后加的板如果没有在建造期标记，滚动时不会动。包络段若被标记，会沿着履带长度直线跑，和链轮脱开。

轮组：

| 零件 | 位置 | 转动 |
| ---- | ---- | ---- |
| 驱动轮 | 后，`z = -(半履带长 - 0.5)` | `markTrackSprocket`，10 颗径向齿，绕局部 X |
| 导向轮 | 前，同高度 | 同样标记，光滑轮加凸缘，没有齿 |
| 支重轮 | 下支 6 个，上支 2 个 | 同样标记。轮体分成左右两段，中间留导向齿的槽 |

外侧有橙色裙板、裙边、螺栓和两端的斜护板。螺栓不投影。履带架在环带内侧，避免挡住履刺。

链轮半径约 `0.42`，轮心高 `0.52`。下支板的高度是轮心减去这个半径，改半径时两处一起改。

## 5. 液压缸

`createHydraulic` 同时给挖掘机、汽车吊和搅拌车用。默认缸筒半径 `0.09`、活塞杆半径 `0.045`。挖掘机在调用处单独加大，不要改默认值。

| 缸 | 名字 | 缸筒 / 杆半径 |
| -- | ---- | ------------- |
| 动臂左右 | `hyd_boom_L` / `hyd_boom_R` | `0.125` / `0.058` |
| 斗杆 | `hyd_stick` | `0.11` / `0.05` |
| 铲斗 | `hyd_bucket` | `0.09` / `0.042` |

缸的局部 Y 从 `from` 指向 `to`。销眼孔沿局部 X，和本场景绕 X 的关节一致。销眼两侧有夹板。运行时 `layoutHydraulic` 按长度缩放 Y，按相对默认半径的倍数缩放 X/Z，销眼留在两端锚点上。

动臂两缸的锚点相对动臂（`x = -0.35`）对称，不是相对整机中线对称。

动臂和斗杆上的软管是 `TubeGeometry`，不投影，挂在对应关节下，弯曲时跟着走，长度不会变。

装饰件（螺栓、履刺、软管、耐磨条）不投影。斗体、侧板、斗齿、主要臂架要投影。

## 6. 机身剪影

这些是附着在现有关节上的细节，不新增动画节点：

- 动臂膝部两侧筋板，斗杆末端颊板，让销接处有厚度。
- 驾驶室门槛、后视镜和门把手。
- 配重上的吊耳。
- 锚点处的销座，避免缸销悬空。

---

## 7. 改模型时核对

- `joint_*`、`hyd_*`、`anchor_*` 的名字还在，建造转角仍是第 2 节那一组。
- 铲斗俯仰仍是 `-1.05` 这一量级。没有为了「斗口朝里」再加 `π`。
- 收臂姿态下：斗底在下，斗口朝机体，斗齿在下刃口，铲斗缸销在斗背而不是斗外。
- 挖掘偏置从 `-0.15` 到 `0.28` 时，斗口相对斗杆仍朝 `-Z` 一侧。
- 下支、上支履带板有标记，前后包络段没有标记。
- `createHydraulic` 的默认半径仍是 `0.09` / `0.045`。吊车和搅拌车的缸没有变粗。
- 铲斗壳体材质仍用独立键。共享的 `tire()` 没有被改成双面。
- 刷新页面后再看。只保存文件，场景里还是上一次建造的网格。
