## 1. 结论摘要

| 问题 | 结论 |
| ---- | ---- |
| 能否用现有 GLB 做出效果图同风格动效？ | **能做出同气质的动态监控页**；像素级 1:1 受模型限制，只能部分对齐。 |
| 与人体全息面板关系？ | **独立病毒面板**；复用 loader / Bloom / 点采样思路 / HUD 叠层模式，**禁止**把病毒逻辑塞进 `HologramPointCloudPreview`。 |
| 运行时资产能否上视口？ | **只用 LOD**。仓库仅保留 `corona_virus_lod.glb`（约 **0.32MB / 10.5 万三角**，Draco）。未减面源模与 Sketchfab 原档已从仓库移除，避免冗余。 |
| 橙红刺突高亮能否按部件选中？ | **原生不能**。mesh 是切分球片段，无 spike 语义。当前用 **整体包围球 `aRadial` + 管状遮罩 + 稀疏 `aSpike`** 近似。 |
| 主方案 | **C 已落地**：独立 WebGL 视口 + 青/金双实例（共享几何）+ 降采样 plexus 第三态 + CSS 右轨 HUD + 轻度 Bloom。 |
| 主体材质 | **自定义 `ShaderMaterial`**，不是 Physical transmission。无 `scene.environment`、无场景灯光对象。观感目标是暗青黑底 + 酒红斑驳 + 灰青玻璃管刺突 + 右缘橙红轮廓，**不再追求通体青玻璃**。 |
| 数据性质 | 演示 Mock；指标文案对齐参考图气质，**不作医疗诊断依据**（与人体 vitals 模块同原则）。 |

已完成推进顺序（历史）：文档边界 → MVP 视口 + 右轨 → 三态对照 → LOD / 刺突近似 → 满屏 HUD + 着色器重做。后续只做人工帧率验收与按效果图微调，不再开新阶段。

### 3.2 GLB 结构（源模解析，2026-11-02；LOD 继承同一拓扑语义）

| 维度 | 事实 |
| ---- | ---- |
| 来源 | Sketchfab *Corona- Virus*；作者 Abdullah EKER；**CC-BY-4.0**（产品中需署名） |
| 材质 | 单材质 `Electric_Animated`：黑底色 + 白 emissive、roughness≈0.6、**无贴图**、OPAQUE — 上屏后全部替换 |
| 动画 | `C4D Animation Take`：对节点 `Virus` 做 **rotation**（约 3s / 91 帧）。**运行时不播 clip**：循环首尾不连续，会像动图跳变；改用代码角速度 |
| Mesh | 多片切分球片段，**非语义部件**（不能 `getObjectByName('spike')`） |
| 节点 | `Virus` → 细分球体；名为 `Background` 的节点加载后剔除 |

对实现的直接含义：

1. **气质必须换材质**：原模是电光自发光，不是参考图的显微玻璃。  
2. **刺突只能着色器近似**（半径 / 法线夹角 / 方位稀疏），或离线拆件重导出。  
3. **旋转走代码**：`VIRUS_FALLBACK_SPIN_RAD_PER_SEC`；尊重 `prefers-reduced-motion`。

### 5.2 加载与构图（`VirusMonitorPreview`）

1. 加载 LOD GLB，剔除 `Background`。  
2. `normalizeVirusContent` 缩放到 `VIRUS_TARGET_SIZE = 2.72`。  
3. 在挂 pivot **之前**做 plexus 采样，避免带上主球位移。  
4. `tagVirusSpikeAttribute` 写入 `aRadial` / `aSpike`。  
5. 主球挂 `mainPivot`，位移 `VIRUS_MAIN_OFFSET = (-1.22, 0.06, 0)`，再按视口宽高比缩放 X。  
6. 金体 / 结构体按 `VIRUS_GOLD_*` / `VIRUS_CLOUD_*` 放置，并夹在右轨 HUD 左侧。  
7. 相机 FOV 28、基准距离 3.35；窄视口按 `VIRUS_MIN_VISIBLE_WIDTH` 拉远。滚轮缩放夹在 2.6–4.6。  
8. 射线命中后可单独拖转主球 / 金体 / 结构体；未拖转时各自连续自转。  
9. 后处理：`RenderPass` → `UnrealBloomPass` → `OutputPass`；ACES，`toneMappingExposure = 1.0`。  
10. **无** Hemisphere / Directional / Point 灯光，**无** `RoomEnvironment`。

## 6. 主体材质与刺突（从实现快照并入）

权威代码：`createVirusMaterials.ts`、`tagVirusSpikeAttribute.ts`、`VIRUS_MAIN_LOOK` / `VIRUS_GOLD_LOOK` / `VIRUS_SPIKE_*`。

### 6.1 着色器结构

主球与金体均为自定义 `ShaderMaterial`（`createVirusMainMaterial` / `createVirusGoldMaterial`），共用顶点着色器，片元着色器换色。

- 大面积明暗：平滑世界法线 + **片元内固定主光/补光方向**（不是场景灯）。  
- 体表：4 层 3D hash 噪声（低频斑驳、中频纤维、高频颗粒）钉在物体空间，随模型转、不随相机漂。细颗粒**只调制颜色**，高光仍用原始法线，避免碎白点。  
- 刺突识别：`aRadial`（整体包围球归一化半径）+「法线 ⟂ 径向」的管状遮罩；半径门槛约 `smoothstep(0.77, 0.86, vRadial)`。  
- `aSpike` 只负责约 **16%** 方位的稀疏橙红尖端（`VIRUS_SPIKE_SELECT_RATIO = 0.16`）。  
- 青边 / 右缘红边按**屏幕固定光位**（法线朝右、红边再限上半部）叠加，不随自转绕球漂移。  
- `FrontSide` + `depthWrite: true`（曾试 DoubleSide 导致刺突穿插碎裂，已弃）。

主球 uniforms 见 `VIRUS_MAIN_LOOK`（rim / redRim / spikeMix / tip / grain / ambient / key / fill）。金体为暗金底 + 高光 spec + 较弱刺突提亮。

### 6.2 `aRadial` / `aSpike` 生成

`tagVirusSpikeAttribute` 用**整棵模型**的包围盒中心与最大半径归一化，而不是每片 mesh 自己的 `boundingSphere`（11 片切分半径不一致时刺突会漂）。

| 常量 | 值 |
| ---- | -- |
| `VIRUS_SPIKE_INNER` | 0.9 |
| `VIRUS_SPIKE_OUTER` | 0.995 |
| `VIRUS_SPIKE_SELECT_RATIO` | 0.16 |
| `VIRUS_SPIKE_POWER` | 2.4 |

算法：归一化半径 → `smoothstep(inner, outer)` 得到尖端权重 → 球面方位量化 hash，超过 selectRatio 则丢掉 → `aSpike = weight ^ power`；全部顶点另写 `aRadial`。

### 6.3 为何放弃 Physical transmission（失败史摘要）

这些路径已证明失败，**不要回退**：

1. 高 transmission + 低 roughness 的湿玻璃 Physical → 像实物 PBR，刺尖大面积粉橙。  
2. 抬全局 emissive + 强 Bloom → 整球洗白。  
3. Fresnel 加在 `totalEmissiveRadiance` 上再叠半透与 Bloom → 中心也糊，不是「仅边缘亮」。  
4. 近景 `RoomEnvironment` PMREM 反射 → 再次过曝。  

阶段 4 结论：显微示意渲染用程序着色器控斑驳与轮廓，Bloom 只吃峰值。

### 6.4 主球外围粒子

挂在 `mainPivot`，随主体转（`createVirusAuraParticles`，斐波那契球面 + 径向抖动）：

| 层 | count | size | opacity | 颜色 |
| -- | ----- | ---- | ------- | ---- |
| aura | 2600 | 0.042 | 0.78 | accent |
| sparkle | 560 | 0.06 | 0.7 | 白 |
| dust | 320 | 0.048 | 0.82 | alert（边缘红点） |

贴图：`createSoftParticleTexture`。Additive 会进 Bloom，但不是主体材质本身。

### 6.5 结构态 plexus

- `sampleVirusVertices`：三角面积加权，避免 LOD 刺突顶点更密导致球壳变稀。  
- 按 `VIRUS_PLEXUS_MEMBRANE_RATIO = 0.82` 拆内膜 / 外刺。  
- 邻域用空间哈希（格子边长 = 连线半径），`maxDegree = 2`。  
- 外刺点径向乘 **0.84** 收短，避免线网糊成实心。  
- 约 9200 点，Additive 电青。

背景星尘 `createVirusStarField`：视锥体积内铺点（约 2200），世界空间慢转，不跟主球。
