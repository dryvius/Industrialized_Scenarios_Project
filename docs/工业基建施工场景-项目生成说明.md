# 三维工业基建施工场景 — 项目生成说明文档

> 本文档为项目需求基线、视觉规范与实现约束的单一事实来源（SSOT）。  
> **主题为「工业基建 / 电力施工可视化场景」。**  
> 技术栈：**Vue 3 + TypeScript + Three.js + Vite**  
> 视觉风格：**Isometric 3D（等距轴测）+ Stylized Low-poly（风格化低多边形）+ Soft PBR（柔和物理材质）**  
> 参考气质：干净通透的工业基建插画（白地、蓝天、橙色工程机械主色）。

---

## 1. 项目定位与角色目标

你是一名资深 Three.js/WebGL 工程师、三维场景设计师和工业可视化前端架构师。

请使用 Vue 3 + TypeScript + Three.js，开发一个具有专业视觉品质的**三维工业基建施工场景**（电力施工 / 基建作业现场） 。视觉风格必须严格遵循本文档中的设计规范。

### 1.1 视觉目标

- 类似高质量工业基建插画、电力施工可视化宣传图。
- 固定斜俯视（等距轴测）视角，同时看到设备顶部、立面与地面。
- 工程车辆与设施造型简洁规整，轮廓清晰，具有真实空间层次。
- 整体**明亮、干净、高对比**，白色地面真正「白得出来」，不做灰蒙蒙效果。
- 不追求电影级写实，追求工程制图般的秩序感与工业专业感。



### 1.2 明确不做

- 不做智慧仓储园区（仓库、货架、月台、叉车物流区等）。
- 不做暗色监控大屏风、重雾效、灰雾笼罩。
- 不做电影级写实、过度夸张透视、塑料高光。

## 2. 视觉风格规范



### 2.1 设计语言


| 维度   | 要求                                           |
| ---- | -------------------------------------------- |
| 构图视角 | Isometric 3D（正交相机等距轴测）                       |
| 造型语言 | Stylized Low-poly / Clean-poly（风格化低多边形，边缘干净） |
| 材质表现 | Soft PBR（哑光工业漆为主）                            |
| 整体气质 | 明亮、通透、高对比、橙色机械点缀白地                           |




### 2.2 与参考图对齐的关键特征

- 大面积近白地面，向远方延伸至浅色丘陵/雪原轮廓。
- 天空为干净浅蓝渐变（可用场景背景色 + 简单天空穹顶/远山表现）。
- 工程机械统一**工业橙**为主色，辅以白、灰、黑。
- 阴影柔和但方向统一，体积感清晰。

---



## 3. 配色与材质规范



### 3.1 配色表


| 对象           | 配色要求                   |
| ------------ | ---------------------- |
| 天空背景         | 清爽浅蓝渐变（上深下浅或上蓝下近白）     |
| 地面           | 近纯白 / 极浅冷白，可有极弱反射感但不刺眼 |
| 远山           | 浅灰白、浅蓝灰层次，简化起伏         |
| 工程机械主体       | 鲜明工业橙                  |
| 驾驶室 / 设备舱    | 白色、浅灰                  |
| 履带 / 轮胎 / 线缆 | 深灰黑、炭黑                 |
| 金属结构件        | 浅灰、银灰哑光                |
| 变电站建筑        | 白色墙体 + 橙色装饰腰线          |
| 输电铁塔         | 白色 / 浅灰格构              |
| 工人服装         | 橙色安全背心 + 安全帽，蓝色工作服可选   |




### 3.2 材质原则

- 以哑光工业漆为主（高 roughness、低 metalness）。
- 橙色要干净醒目，避免发灰发脏。
- 白色地面与建筑要够亮，避免被环境光染成灰雾。
- 禁止整物体表面「选中蓝膜」；选中应为四周光圈 / 描边框。

## 4. 场景布局要求

创建一个完整的三维工业基建施工现场，必须包含以下内容：

1. **大面积近白地面**，并向远景过渡到浅色丘陵/雪原。
2. **清爽蓝天背景**（背景色或简易天空表现）。
3. **随车吊 / 起重机卡车**（白色驾驶室 + 橙色起重臂 + 支腿）。
4. **履带挖掘机**（橙色机身 + 动臂/铲斗）。
5. **履带式混凝土搅拌车**（白色滚筒 + 橙色色带 + 履带底盘）。
6. **电缆卷盘车**（大型卷盘 + 黑色缆线示意 + 拖车/动力单元）。
7. **输电铁塔**（格构示意，控制面数，保证远处轮廓可读）。
8. **变电站 / 附属小建筑**（白墙 + 橙色腰线，可带简化电气构件）。
9. **若干小型设备**（发电机、工具箱车等橙色小单元）。
10. **工人示意模型**（低多边形，提供尺度感，3～8 人即可；含塔上高空作业示意，见 [`杆塔高空作业实现说明.md`](./杆塔高空作业实现说明.md)）。
11. **地面线缆 / 作业痕迹**（简化线段或细管，点到为止）。



### 4.1 空间逻辑约束

- 设备间距合理，作业面通行关系清晰。
- 比例符合工程常识（人、车、塔、建筑尺度匹配）。
- 禁止无组织随机方块堆砌代替完整场景。
- 程序化建模优先；复杂关节可用分段几何近似。

## 5. 相机与构图规范



### 5.1 相机类型

- 使用 **OrthographicCamera（正交相机）** 营造等距轴测效果。
- 默认展示完整施工现场主体。
- 不要使用过度夸张的透视效果。



### 5.2 构图原则

- 相机从场景上方斜向下观察。
- 工程机械集群与铁塔/变电站构成主视觉。
- 四周留白充足，突出「白地舞台感」。
- 支持窗口尺寸变化及画布自适应。



### 5.3 交互控制

- OrbitControls 有限旋转 / 缩放 / 平移。
- 旋转角度受限，避免破坏等距观感。

---



## 6. 光照与阴影规范



### 6.1 光源策略

- 明亮方向主光（可略偏暖）+ 适中环境光。
- 阴影方向统一，避免多主光造成冲突阴影。
- **禁止使用会把画面染灰的强雾效。**



### 6.2 阴影与层次

- 为车辆、铁塔、建筑、人物提供柔和接触阴影。
- 保持高对比：白要白、橙要橙、影子清楚但不死黑。
- 曝光以「干净通透」为准，避免灰蒙与过曝塑料感。

## 7. 前端技术要求



### 7.1 技术栈

- Vue 3 Composition API
- TypeScript
- Three.js
- Vite
- Pinia（场景选中与对象信息状态）



### 7.2 实现要求（强制）

1. 创建独立的三维场景组件。
2. 场景初始化、模型构建、相机控制、交互拾取、资源释放拆分为独立模块。
3. 可复用几何体、共享材质；重复小物件优先 InstancedMesh。
4. 清晰的场景对象命名与分组。
5. OrbitControls 有限旋转 / 缩放 / 平移。
6. 点击对象高亮：**物体四周光圈 / 描边框**，禁止表面蓝膜覆盖。
7. 预留业务数据绑定接口（设备状态、工单、人员等可后续接入）。
8. 组件卸载时正确释放几何体、材质、纹理、监听器、渲染器。
9. 控制模型复杂度，保证普通办公电脑浏览器流畅运行。
10. **不要把所有代码写进一个 Vue 文件。**



### 7.3 架构建议目录

```text
src/
  api/                 # 业务数据绑定（设备/工单 Mock）
  components/          # 场景组件、信息面板
  composables/         # 场景生命周期封装
  constants/           # 配色、布局常量
  enums/               # 场景对象类型
  scene/               # Three.js 核心与建造器
    builders/          # 地面/铁塔/变电站/人物等
      vehicles/        # 车辆域：单车 Builder + VehicleSystemBuilder 聚合
        shared/        # 液压缸、车轮等跨车复用零件
  stores/              # Pinia 状态
  types/               # TypeScript 类型
  styles/              # 全局样式
```

## 8. 建模实现策略



### 8.1 建模优先级

优先使用**程序化建模**构建：

- 地面与远山
- 随车吊、挖掘机、搅拌车、卷盘车
- 变电站建筑、小型设备
- 工人示意体
- 线缆示意

输电铁塔使用**示意级格构**（控制段数），保证轮廓正确即可。

车辆驾驶室可复用既有卡车车头建模经验（分块车身、透明/深色车窗、黑胎灰毂）。

### 8.2 重复对象优化

- 共享 Geometry / Material。
- 工人、小设备、线缆卡具等可实例化。
- 避免无必要的超高段数圆柱与细碎零件。



### 8.3 质量底线

- 尺寸、朝向、层级、空间位置合理。
- 橙色机械与白色环境形成明确主次。
- 选中反馈为光圈，不破坏材质观感。

## 9. 交互与业务数据预留



### 9.1 选中交互

- 点击工程车辆、铁塔、变电站、设备、人员等可选对象。
- 选中表现：地面光圈 + 包围描边（或等效光圈），**禁止整面发光蓝膜**。
- 支持清除选中。



### 9.2 数据接口建议

- `fetchSummary`：现场概况（设备数、作业状态等）
- `fetchEntityByKey`：按业务主键查详情
- `fetchMachines`：工程机械列表
- `fetchWorkers`：人员列表（可选）
- `fetchFacilities`：铁塔 / 变电站等设施列表

## 10. 从仓储项目迁移的改造清单

改造时按下列顺序推进，并删除不再使用的仓储专用模块：

1. **更新本文档与 README 主题描述。**
2. **调整配色、背景、光照、相机目标**（白地蓝天明亮风）。
3. **替换地面建造器**：近白大地 + 远山。
4. **新增/替换车辆建造器**：吊车、挖机、搅拌车、卷盘车。
5. **新增设施建造器**：铁塔、变电站、小设备、工人。
6. **移除仓储专用建造器**：仓库、货架、月台、园区围栏货架体系等。
7. **更新对象类型枚举、Store、API Mock、信息面板文案。**
8. **保留并校验选中光圈交互与资源释放。**
9. **验收构图、色彩通透度、性能。**

## 12. 验收标准（Checklist）



### 12.1 视觉验收

- [ ] 正交等距轴测成立，现场主体完整入画
- [ ] 白地 + 蓝天通透，无明显灰雾感
- [ ] 工程机械橙色鲜明，层次清晰
- [ ] 无仓储货架/月台等旧主题残留（或已完全替换）



### 12.2 场景完整性验收

- [ ] 地面与远景成立
- [ ] 至少 3 类工程车辆可读
- [ ] 铁塔与变电站/附属建筑可读
- [ ] 小设备与工人尺度成立



### 12.3 工程验收

- [ ] 代码模块化，非单文件堆叠
- [ ] 选中为光圈/描边，非表面蓝膜
- [ ] OrbitControls 有限交互可用
- [ ] 卸载资源释放正确
- [ ] 普通办公电脑浏览器可流畅运行



### 12.4 运行验收

```bash
npm install
npm run dev
npm run build
npm run preview
```
