# 杆塔高空作业实现说明

> 本文档描述输电铁塔上的**示意级攀爬 + 多挂点作业**方案与实现约定。  
> 与 [`场景动画与动作实现说明.md`](./场景动画与动作实现说明.md)（动画总册）、[`人员模型优化方案说明.md`](./人员模型优化方案说明.md)（工人网格与关节契约）、[`场景穿模与物理碰撞方案说明.md`](./场景穿模与物理碰撞方案说明.md)（物理边界）、[`工业基建施工场景-项目生成说明.md`](./工业基建施工场景-项目生成说明.md)（场景基线）配套。  
> 定位：**阶段 3.5** — 在程序化工人关节上做可读的塔上作业演示，非游戏级攀爬 / 非 GLTF 骨骼。

---

## 1. 背景与范围

### 1.1 目标

| 能力 | 要求 |
| ---- | ---- |
| 攀爬到指定位置 | 沿塔腿横栏升至挂点 `anchorId`，姿态为**贴塔攀爬**（非地面走步） |
| 多挂点作业 | 同时支持塔身中段、下层横担、上层横担 |
| 塔身作业朝向 | 中段作业**面向塔心/格构**，不得背对塔身 |
| 横担移动 | 沿横担弦杆**骑跨挪移**（双腿夹架），不是横担上走路 |
| 作业循环 | 到位后示意点检 / 持工具小幅循环 |
| 回降 | 贴塔攀爬姿态下降回塔基 |

### 1.2 明确不做

- 手指级抓格构、双绳安全带动力学  
- NavMesh / 全物理攀爬、与塔身 Fixed 盒实时推挤  
- GLTF 骨骼攀爬片（见动画文档阶段 4）  
- 地面 `WorkerLocomotionController` 步态直接上塔（其假设 `y≈0`）  
- 横担上复用 walk / run 步态  

### 1.3 与阶段 3 的关系

动画文档阶段 3 的「不做真实攀爬」指**地面人员系统不引入攀爬状态机**。  
本专文的塔上攀爬是**独立控制器**（`TowerWorkController`），仅用于高空作业人员。

## 2. 状态机

```text
Idle → Climb(vertical) → Work(mast, 面朝塔)
     → Climb(vertical) → Straddle(横担挪移) → Work(arm, 保持骑跨) → …
     → Descend(vertical climb pose) → Idle
```

| 状态 | 行为 |
| ---- | ---- |
| `idle` | 塔基外侧待机姿态 |
| `climb` | **竖直**沿横栏贴塔攀爬：上手抓上一档、腿蹬当前档；始终面朝塔心 |
| `straddle` | **水平**沿横担骑跨挪移：双腿夹弦杆，躯干前倾，夹腿式前移 |
| `work` | 钉在挂点作业；塔身面向塔心，横担保持骑跨坐姿 |
| `descend` | 竖直贴塔下降回塔基 |

`play()` 无参时跑默认 demo：`mast_mid` → `arm_lower` → `arm_upper` → 下降 → 循环。

## 3. 挂点 SSOT

### 3.1 坐标系

1. 挂点先以**铁塔本地坐标**定义（原点在塔基中心，+Y 向上，横担沿 ±X）。  
2. 经 `getFacilityOrientations().pylonRotY` 绕 Y 转到世界系，再平移 `FACILITY_LAYOUT.pylonX/Z`。  
3. 代码入口：`src/scene/layout/pylonAnchors.ts`。

### 3.2 预置挂点

| `anchorId` | 含义 | 本地高度（约） | 作业朝向约定 |
| ---------- | ---- | ------------- | ------------ |
| `mast_mid` | 塔身中段外侧 | `height * 0.45`（吸附横栏） | **面向塔心**（`facingYaw` 指向原点） |
| `arm_lower` | 下层横担作业 | `height * 0.58` | 沿横担轴向；移动/作业用骑跨 |
| `arm_upper` | 上层横担作业 | `height * 0.76` | 同上 |

尺度来自 `PYLON_SCALE`（塔高 30 m）。

### 3.3 攀爬路径构造

- **上塔身**：塔基 → 主腿**按横栏一档一点**升高 → 目标挂点。  
- **上横担**：先竖直爬到横担高度近塔处，再**水平段**沿横担外移到挂点（该段用骑跨挪移，不用走步）。  
- 路径点为世界系 `{x,y,z}`，由 `buildClimbPath(from, targetId)` 生成。  
- 横栏间距 SSOT：`PYLON_CLIMB.rungSpacing`（默认 0.42 m）；脚钉网格与竖直路径、攀爬手脚相位共用。  
- **手脚接触**：脚钉贴主腿（`pegOutward≈0.12`，不可外飘）；人站 `bodyOutward≈0.48`，脚踩钉、手屈肘抓钉外侧。竖直步前半段身体停在下档；不靠加大 pegOutward 迁就抓点。  
- **横担骑跨线**：坐点 `armSitLift` 抬到弦杆上方，`armRideZ` 前偏避开腹杆，再沿 ±X 挪移。

## 4. 控制器设计

### 4.1 类与接口

- 文件：`src/scene/animation/controllers/TowerWorkController.ts`  
- 实现 `SceneAnimator`  
- `play(action?, options?)`：
  - `climb` + `options.target`：前往挂点（自动竖直攀爬 / 横担骑跨）  
  - `work`：在当前挂点作业  
  - `descend`：回塔基  
  - 无参 / `demo`：多挂点演示循环  

### 4.2 竖直攀爬（示意级，非走路）

- 根节点按横栏折线推进；**朝向始终面朝塔心**（上/下塔相同）。  
- 姿态特征：躯干前倾贴塔、双手上举交替抓上一档、双腿交替蹬踏当前档；**禁止**地面 walk 式前后迈步感。  
- 相位与横栏档位同步：爬过一档 ≈ 半复步。  
- 直接写 `Object3D.position`（含 Y），不走地面 `RootPoseDriver`。

### 4.3 横担骑跨挪移

- 路径中以水平为主的段（上横担）切换为 `straddle` 姿态。  
- 双腿外展夹住弦杆示意，髋部略降，躯干前倾；前移靠夹腿/髋部小幅挪动脉冲，**不是**走跑步态。  
- 到位作业时保持骑跨坐姿，再叠加点检/持工具上肢循环。

### 4.4 作业朝向与姿态

| 挂点类型 | 朝向 | 下肢 |
| -------- | ---- | ---- |
| 塔身中段 | 强制 `faceTowardPylon` | 站立扶塔作业 |
| 横担 | 沿横担轴向 | 保持骑跨 |
