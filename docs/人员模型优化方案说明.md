# 人员模型优化方案说明

> 本文档是程序化工人的**网格、比例与近景观察**约定。  
> 动作驱动见 [`场景动画与动作实现说明.md`](./场景动画与动作实现说明.md)，塔上攀爬见 [`杆塔高空作业实现说明.md`](./杆塔高空作业实现说明.md)，场景基线见 [`工业基建施工场景-项目生成说明.md`](./工业基建施工场景-项目生成说明.md)。  
> 定位：等轴测、示意级低多边形施工人员。近景能分辨工种和服装，不做电影级写实，不换 GLTF 骨骼。

---

## 1. 目标与边界

### 1.1 要达到的效果

| 项 | 要求 |
| -- | ---- |
| 可读性 | 点击聚焦后能看清帽色、背心、五官和工种配件 |
| 身高 | 仍按每名工人标注的站立身高（头顶，不含安全帽） |
| 动作 | 走、跑、爬塔继续驱动同一套关节，网格跟着关节转 |
| 连接 | 颈、肩、腰、髋、肘、膝在静止和摆动时都连成一体，不出现中空或从衣服里穿出 |

### 1.2 明确不做

- 蒙皮、形变、按步态改网格顶点  
- 移动 `joint_*` 的枢轴位置来“修比例”  
- 为近景单独做一套高模，或与现有关节并行维护第二套工人  
- 用全周宽帽檐遮脸（当前相机最低大约在水平面上方 19°，宽檐会挡住眼睛）

## 2. 七名工人

规格写在 `WorkerBuilder.build()`，站位来自 `SITE_LAYOUT.workers`。帽色只表示职责大类，同帽色用工种配件区分。

| ID | 角色 | 帽 | 工种 `kit` | 姿态 | 身高 | 运行时动作 |
| -- | ---- | -- | ---------- | ---- | ---- | ---------- |
| `worker_01` | 班组长 | 红 | `foreman` | `point` | 1.80 | 原地 |
| `worker_02` | 巡检员 | 白 | `inspector` | `idle` | 1.72 | 走 |
| `worker_03` | 电工 | 蓝 | `electrician` | `idle` | 1.78 | 跑 |
| `worker_04` | 放线工 | 蓝 | `linesman` | `carry` | 1.75 | 走，持线圈 |
| `worker_05` | 巡检员 | 白 | `surveyor` | `point` | 1.68 | 原地 |
| `worker_06` | 起重工 | 蓝 | `rigger` | `idle` | 1.85 | 原地 |
| `worker_07` | 高空作业 | 蓝 | `climber` | `towerWork` | 1.76 | `TowerWorkController` |

配件挂点：对讲机、望远镜在胸前；手电、工具包在髋；线圈、指挥棒在右肘；安全带在躯干和两条大腿上。头灯只给攀爬工。

脸朝 **+Z**。肘关节绕 X 负向转时，前臂折向 +Z；护肘放在肘的 **-Z**（肘后），不要放在胸前。

## 3. 关节契约

`tagAnimatable` 用下面的名字查找关节。`WorkerLocomotionController` 与 `TowerWorkController` 只写这些节点的旋转（以及髋的少量位移）。**改网格时不要改这些局部坐标。**

| 节点 | 父级 | 局部位置 |
| ---- | ---- | -------- |
| `joint_hips` | 根 | `(0, 0.88, 0)` |
| `joint_spine` | 髋 | `(0, 0.12, 0)` |
| `joint_arm_L/R` | 脊柱 | `(±0.3, 0.48, 0)` |
| `joint_elbow_L/R` | 上臂 | `(0, -0.3, 0.02)` |
| `joint_thigh_L/R` | 髋 | `(±0.13, -0.03, 0.01)` |
| `joint_calf_L/R` | 大腿 | `(0, -0.42, 0.01)` |
| `joint_foot_L/R` | 小腿 | `(0, -0.38, 0.02)` |

姿态只影响手臂，不改枢轴：

| 姿态 | 上臂 | 肘静止角 | `lockSwing` |
| ---- | ---- | -------- | ----------- |
| `idle` | `x=0.12`，`z=±0.08` | `-0.2` | 否 |
| `point` | 仅右侧 `x=-0.85`，`z=-0.15` | 右 `-0.08` | 仅右臂 |
| `carry` | `x=-0.55`，`z=±0.25` | `-0.78` | 双臂 |
| `towerWork` | `x=-0.35`，`z=±0.12` | `-0.48` | 双臂 |

锁定的手臂在走路时保留建造时写入的 `userData.idleRotation`，肘只在这个角度上做小幅抽动。未锁定的走/跑仍用步态自己的屈肘。这样持线圈的放线工不会被步态把胳膊拉直。实现：`WorkerLocomotionController.applyElbowBend`。

跑的大腿摆幅约 **±0.68 rad**，摆动期小腿弯曲约 **0.95 rad**。网格必须在这个幅度下仍然连在衣服上。走的摆幅较小（大腿约 ±0.38 rad），以跑作为穿模验收。

## 4. 身高

基准骨架头顶（不含帽）为 **1.84**，常量 `WORKER_SCALE.modeledCrownHeight`。

```text
根缩放 = 标注身高 / 1.84
头顶世界 y = joint_hips.y + joint_spine.y + 头本地顶
           = 0.88 + 0.12 + 0.84
           = 1.84
```

头本地顶是颅骨中心 `y=0.69` 加半径 `0.15`。安全帽在这之上，不计入身高；`helmetExtra` 仍为 0.12。脚底在缩放前大约贴在 `y≈0`，不要为了比例去压低鞋底。

把头、颈、帽作为一组一起升降。只降头不改 `modeledCrownHeight`，标注身高会变矮；只改常量不降头，全身会被放大，腿会变长。

当前相对早期骨架把冠高从 1.94 收到 1.84，全体工人大约放大 5%。`PYLON_CLIMB.bodyOutward` 等爬塔外探是按旧尺度调的，近看手脚与横档时如果差一截，改爬塔常量，不要回头改关节枢轴。

## 5. 网格怎么跟着关节

没有蒙皮。一块网格属于哪个关节，摆动时就跟着那个关节转。优化时遵守三条：

1. **会转的体积挂在会转的关节上。** 裤管是大腿网格，袖管是上臂网格。髋上的裤身只盖到髋折，不要做成包住大腿的裙子。  
2. **接缝用重叠挡住，不要用空隙表示关节。** 颈、肩、腰、髋、肘、膝都要让相邻体积互相埋进对方。肩球挂在**脊柱**上，不挂在上臂上，否则指向姿态会把三角肌甩离胸口。  
3. **静止壳不要占住摆动扫过的空间。** 绕 X 摆腿时 X 不变、Y/Z 在变。裆部可以留在两腿之间的窄缝里（现在半宽约 0.028，大腿内缘约在 `x=0.04`），不要做一块又宽又深的胯下盒子。反光圈要埋进肢体，只露出一圈边；反光条要落在背心各面的内侧，不要用一根比背心更宽的横条。

几何在每次 `WorkerBuilder.build()` 里新建。`ResourceDisposer` 会在拆场景时释放网格几何；模块级缓存会在下一次进场景时变成已释放的缓冲。材质走 `MaterialFactory`，可以共用，不要随网格一起丢。

## 6. 已处理的问题和做法

### 6.1 关节中空、肩和背心悬空

早期四肢是分开的胶囊和球，环带的主半径大于肢体，颈、腰、髋、肘、膝能看见缝。肩部用了一块很宽的轭和过大的肩球，背心浮在身体外面。

做法：肢体加长并互相重叠；轭缩小；肩球改挂脊柱；背心前片、后片、侧片嵌进胸腹；颈根加粗；下颌带收进头盔；去掉悬浮的帽钉。宽帽檐会在允许的相机俯角下挡住脸，只保留短帽舌。

### 6.2 躯干过长

背心从下巴铺到腰带，腰身再叠一截，腿显得短。下巴到腰带大约 0.68（按当时冠高 1.94），头心比肩关节高出约 0.33。

做法：缩短胸、腰和背心，头、颈、头盔一起下降约 0.10，冠高改为 1.84。背心只盖胸口和上腹，下面是衣摆和腰带。腰的深度与胸一致，底边接到腰带，避免腰侧再露出一条空缝。

### 6.3 反光条和臂环悬空

前后各一根全宽横条，比橙色背心宽，斜向看时两端悬在身体两侧。臂环、小腿环是套在肢体外面的圆环。

做法：胸前背心合成一整块；反光条分别贴在前、后、侧面，并缩进背心边缘，同一高度绕身一圈。环的主半径小于肢体半径，管子大部分埋进布料。

### 6.4 走、跑时腿穿出裤子

髋上的骨盆和胯下盒子包住了大腿上段。大腿绕髋摆动时，这条腿从固定的裤身前后面穿出去。关节不能下移，所以不能靠改枢轴解决。

做法：

- 裤身收到髋折（骨盆底大约在髋局部 `y=-0.06`）。  
- 胯下只留一条窄裆，填两腿之间的缝，不占大腿的 X 范围。  
- 大腿胶囊顶部落在髋关节附近，并与髋球重叠；膝盖以下仍由小腿关节接管。摆动时看到的是裤管在转，不是腿从一块固定布料里钻出来。

站立时若髋下重新出现空洞，用髋球和窄裆补，不要把裤身再次拉长盖住大腿。

## 7. 点击聚焦

聚焦按被点物体的包围盒投影计算，不使用统一的近景距离。`CameraController.resolveFocusZoom` 把包围盒 8 个角投到视图里，让较紧的一边占满 `focusFill`（0.78）。正交相机可见高度是 `frustumSize / zoom`（`frustumSize` 为 76）。

`camera.maxZoom` 为 **40**，否则工人所需的缩放（大约二十多）会被夹在旧上限 4，画面高度仍约 19 m。`minZoom` 仍为 0.4。只插值目标和缩放，不改相机朝向。

`OrbitControls` 的 `maxZoom` 在相机构造时写入。改 `src/constants/scene.ts` 里的缩放上限后需要刷新页面，热更新不会改已经创建的控制器。

---

## 8. 改模型时核对

- 关节名和局部位置与第 3 节一致。  
- 颅骨顶本地 y 仍是 0.84；若移动头部，同步修改 `modeledCrownHeight`。  
- 鞋底没有沉到地平线以下。  
- 肩球仍在脊柱下；护肘仍在 -Z。  
- 反光条没有超出背心轮廓；臂环、腿环没有套在肢体外面。  
- 裤身没有重新包住大腿扫过的区域。用跑姿（`worker_03`）看前后摆腿，用持物走姿（`worker_04`）看锁定的肘是否还弯着。  
- 几何仍在 `build()` 内创建，没有恢复成跨场景缓存。
